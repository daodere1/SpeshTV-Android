# SpeshTV Android and Android TV

SpeshTV is an independent customized fork of Moonfin-Core. This repository
contains shared Flutter source and native Android playback integrations for
phones, tablets, Android TV, Google TV and Fire TV.

The Cinematic interface includes Studios discovery, local-first search and
progress, framed season/episode browsing, a Today-forward Eastern-time calendar,
and a remote-friendly Live TV guide. Native playback, HDR capabilities and
channel favorites are retained.

Application IDs, signing identity, stored preference keys, platform-channel
names and compatible server API aliases are retained so existing installations
and server plugins keep working. Internal package names are not product labels.

Upstream and third-party credits and licenses remain in the source and LICENSE.
SpeshTV is not an official Moonfin release and does not include media or provider
credentials. See README.md for build instructions and supported download targets.
